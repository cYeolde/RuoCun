# 若存 Agent 工具速查

## 先分清三方

模型收到本轮可见的**工具名、说明、参数 schema**，据此选择并生成 JSON 调用；若存本地程序按名称查 `ToolRegistry`，校验最终参数，过模式、Hook、权限等关，再调用对应 `handler`。本地 handler 打开文件、运行命令或访问服务；真实结果按调用 ID 回到下一次模型输入。注册、可见、获准执行是不同状态。入口见 [`runtime.py`](../src/ruocun/agent/runtime.py) 的 `_registry`、[`registry.py`](../src/ruocun/tools/registry.py)、[`tool_batch.py`](../src/ruocun/tools/tool_batch.py)。

## 查找、读取、编辑

| 工具 | 做什么、怎样做 |
| --- | --- |
| `ListDir` | 列某个目录的条目，适合先看目录层级。 |
| `Glob` | 按文件名/相对路径模式遍历，例如 `**/prices.mjs`；只返回匹配路径，不读内容。 |
| `Grep` | 遍历文件，用正则匹配**内容**；可返回命中行、文件名或计数。明确报错优先搜原文。 |
| `Read` | 读取文件文本或支持的图片，并记录目标文本文件的读取基线；图片能否理解还取决于所选模型的视觉能力。 |
| `Edit` | 对已读文本做局部旧文替换；默认要求唯一匹配，检查基线，在文件锁内原子写入。 |
| `Write` | 写入整份文件；用于新建或明确重写，覆盖范围需谨慎核对。 |
| `RepoMap` | 提取支持语言的定义签名，按预算给模型一份代码结构地图；是定位线索，不代替查实际调用链。 |
| `LSP` | 有用户/项目语言服务器配置时才注册；向服务请求定义、引用、符号、悬停和调用关系。 |

## 命令、网页与外部能力

| 工具 | 做什么、怎样做 |
| --- | --- |
| `Bash` | 运行命令行程序，可跑测试、构建、脚本或其他命令；Windows 默认解释器是 cmd，命令需过权限检查。 |
| `BashOutput` / `KillShell` | 对受管后台命令读取新增输出 / 请求停止并核实终态。 |
| `WebSearch` / `WebFetch` | 搜网页结果 / 抓取网页并可按提示抽取；关闭 web 时不注册。 |
| `ToolSearch` | 搜索并激活延迟工具或 MCP 工具；返回定义不等于已执行那个工具。 |
| `Skill` / `SkillInstall` | 读取已发现的技能流程 / 安装完整技能资源；技能正文给模型指导，真正动作仍由其他工具完成。 |
| `Config` | 按需加载的配置操作。 |
| `mcp__…` | 经 MCP 连接外部服务器提供的工具；可见性和调用仍受若存侧校验与权限约束，服务端也会执行自身逻辑。 |

## 规划、交互与会话

| 工具 | 做什么、怎样做 |
| --- | --- |
| `TodoWrite` | 更新本轮任务清单，不直接修改项目文件。 |
| `EnterPlanMode` / `ExitPlanMode` | 切换只读规划和执行状态；派发时会重查当前模式。 |
| `AskUserQuestion` / `SendUserMessage` / `NotifyUser` | 询问用户 / 向终端发正文或附件 / 发尽力而为的终端提示。 |
| `MemoryRead` / `MemoryWrite` | 读取或写入长期记忆；旧记忆需要核对当前项目事实。 |
| `ArchiveRead` | 从会话归档取原始记录，不是重新执行旧工具。 |
| `EnterWorktree` / `ExitWorktree` | 进入或退出隔离工作树；目录变化影响后续相对路径。 |
| `CronCreate` / `CronDelete` / `CronList` / `Schedule` | 在支持的平台管理系统日程或调度；与只在当前会话运行的 `/loop` 不同。 |

## 子代理与后台任务

| 工具 | 做什么、怎样做 |
| --- | --- |
| `Agent` / `TaskCreate` | 发起子代理或任务。 |
| `TaskList` / `TaskGet` / `TaskUpdate` | 列任务、查任务、更新任务状态。 |
| `TaskSend` / `MessageParent` | 向子代理追加要求 / 子代理向父代理汇报。 |
| `TaskOutput` / `TaskWait` / `TaskStop` | 读取任务输出、等待后台事件、请求停止并核对。 |
| `Monitor` | 按行跟踪受管命令输出。 |

这些是源码注册或按条件加载的能力，**不是每一轮模型都能看到全部工具**。例如 RepoMap 与 LSP 可延迟暴露，LSP 无配置不注册，Web 工具可关闭，计划模式会隐藏或拦截写入与执行能力。工具定义告诉模型“能申请什么”，本地派发与权限决定“现在能否真的做”。
