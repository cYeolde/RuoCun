这套 21 章中文学习笔记结合源码和项目案例，讲清 Agent harness 的关键设计与取舍。学完能用具体例子回答相关面试题。如果你调过 API，还没拆过 Agent 的主循环，可以从第一章的一次查价读起。按题复习时，在 C 真实面经中点击题干即可。
